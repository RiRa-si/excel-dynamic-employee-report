# Excel Dynamic Employee Report

This is a simple Excel project I made to practice dynamic formulas and reporting in Excel.

The main idea of this project is to create a report where I can select a department from a dropdown and the employee data, summary numbers, and chart update automatically.

## What I used

* Excel
* FILTER
* SORT
* UNIQUE
* COUNTIFS
* AVERAGEIFS
* SUMIFS
* Data Validation
* Excel Charts

## What the report does

I created a department dropdown with:

* IT
* HR
* Finance

After selecting a department, the report automatically shows:

* Employees from that department
* Number of employees
* Average salary
* Total sales
* Sales chart

For example, if I select **IT**, only the IT employees are displayed and the summary values change automatically.

## What I learned

While making this project, I practiced how different Excel functions can work together to create a dynamic report instead of manually changing the data every time.

I also got more practice with dynamic arrays, filtering, sorting, and basic dashboard-style reporting.
